# LooWhere?

A crowd-sourced public toilet finder for Singapore, built for NUS Orbital 2026.

We were awarded an Honourable Mention for this project!

## What is this

Finding a decent public toilet in Singapore is harder than it should be. You never know if it has a bidet, if there's toilet paper, or if it's wheelchair accessible until you're already there. LooWhere lets users check a map for toilets near them, see what facilities they have, read reviews from other people, and add new toilets that aren't on the map yet.

## Features

- Interactive map of 720+ real toilet locations in Singapore, pulled from OpenStreetMap
- Ratings and reviews for each toilet
- Users can submit new toilets, which get reviewed by admins before going live
- Search and filter by amenities like bidet, accessibility, toilet paper
- Save toilets you use often for quick access later
- A points and ranking system for users who contribute
- Admin dashboard for moderating submissions

## Tech stack

- React Native + Expo for the app
- Supabase for the database, auth, and storage
- Google Maps API for the map
- OpenStreetMap data for the initial toilet locations
- Jest for testing
